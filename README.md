# 🎓 BunkBuddy — Smart Academic Attendance & Performance Predictor

BunkBuddy is a production-ready Flask web application designed to help university students optimize their academic schedules, track attendance thresholds, and forecast GPA trajectories using Machine Learning.

🚀 **Live Deployment:** [Launch BunkBuddy Live App](https://bunkbuddy-z76j.onrender.com/)
---

## ✨ Core Features

* **Dynamic Bunk Calculator:** Computes precise, minimal lecture attendance margins to maintain university compliance.
* **Predictive CGPA Engine:** Forecasts multi-attribute academic performance using underlying lifestyle parameters.
* **Automated Risk Alerts:** Generates structural warnings mapping student stress levels and internal grading metrics.

---

## 🛠️ Tech Stack & Architecture

* **Backend Framework:** Python, Flask
* **Machine Learning Pipelines:** Scikit-Learn (Linear Regression)
* **Frontend UI Layer:** Responsive HTML5, Vanilla CSS3
* **Data Source:** Curated Student Attributes Pipeline (Kaggle Dataset Engine)

---

## 📊 Machine Learning Model Details

The predictive core utilizes a validated Linear Regression model trained on multi-dimensional student performance metrics.

* **Model Evaluation Metric:** $R^2$ Score of **85%**
* **Tracked Feature Parameters:** Attendance Rates, Weekly Study Hours, Sleep Cycles, Quantified Stress Levels, Historical Internal Marks.

## ⚙️ Local Development & Installation

### 1. Clone the Repository
```bash
git clone https://github.com
cd BunkBuddy
```

### 2. Install Required Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Local Development Server
```bash
python app.py
```
After executing, navigate to `http://127.0.0` in your browser.
