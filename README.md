# 🎓 BunkBuddy — Multi-Dimensional Academic Performance Predictor

[![Live App](https://shields.io)](https://bunkbuddy-z76j.onrender.com/)

**BunkBuddy** is a production-ready web application designed to assist university students with optimizing academic schedules, tracking attendance thresholds, and forecasting GPA trajectories. The architecture features an engineered **Scikit-Learn linear regression pipeline** integrated into a scalable **Flask** backend to deliver real-time predictive analytics based on student behavioral parameters.

### ✨ Core Features & Workflows
* **Predictive CGPA Engine:** Evaluates student lifestyle attributes in real time to forecast multi-attribute academic performance.
* **Deterministic Bunk Calculator:** Computes precise, minimal lecture attendance margins required to maintain university regulatory compliance.
* **Proactive Risk Matrix:** Tracks critical multi-dimensional data correlations to flag optimization warnings before performance drops.

---

### 🛠️ Tech Stack & Systems Architecture
* **Core Language:** Python 3.x
* **Backend Framework:** Flask (Routing, API Endpoints, Request Parsing)
* **Machine Learning & Analytics:** Scikit-Learn, Pandas, NumPy
* **Data Visualization & Front-End:** HTML5, Vanilla CSS3 (Fully Responsive Grid Layout)
* **Cloud Infrastructure & Hosting:** Render (Production Web Service Pipeline)

---

### 📊 Machine Learning Pipeline & Model Evaluation
The analytical core models academic performance by evaluating a multi-dimensional feature space derived from a comprehensive historical student dataset.

* **Model Architecture:** Generalized Linear Regression (`scikit-learn`)
* **Model Evaluation Metric:** **R² Score of 85%** on cross-validated test distributions.
* **Tracked Feature Parameters:** 
  * *Attendance Rates* (Continuous temporal tracking)
  * *Weekly Focused Study Hours* (Metric tracking)
  * *Quantified Sleep Cycles & Stress Metrics* (Categorical behavioral logs)
  * *Historical Internal Evaluation Marks* (Performance baseline tracking)

#### 1. Clone the Architecture
```bash
git clone https://github.com
```

#### 2. Initialize Dependencies
```bash
pip install -r requirements.txt
```

```bash

```
